# FlashNotes

Proyecto personal de entretenimiento, con una API REST y un cliente web de estética de terminal.

*Este repositorio es la vitrina del proyecto: reúne en un solo lugar sus dos repositorios, el backend y el frontend.*

## Dónde verlo

- Backend: https://github.com/JuanJo0775/flashnotes-backend
- Frontend: https://github.com/JuanJo0775/flashnotes-frontend

## Arquitectura

- **Backend:** API REST con Node.js, Express y MongoDB.
- **Frontend:** cliente web con Next.js, React y TypeScript, estilizado con Tailwind CSS.

## Tecnologías

Node.js, Express, MongoDB, Next.js, React, TypeScript y Tailwind CSS.
